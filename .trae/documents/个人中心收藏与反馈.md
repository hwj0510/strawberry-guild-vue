# 个人中心、我的收藏与用户反馈

## Context

截图中的用户下拉菜单已有“个人中心”和“我的收藏”，但目前没有页面或跳转。此次将接通这两个入口，支持修改个人资料、查看和取消收藏，并在同一菜单新增“用户反馈”入口。前端继续调用现有 Spring Boot 真实接口，不用 localStorage 伪造业务数据。

## 实现方案

### 1. 路由与导航

- 修改 `src/router/index.js`，在 `MainLayout` 的认证子路由中增加 `/profile` 和 `/favorites`，复用现有登录守卫。
- 修改 `src/layout/MainLayout.vue`：为“个人中心”“我的收藏”补充菜单 command 和路由跳转；新增“用户反馈”菜单项及反馈弹窗；资料更新后沿用 `authStateRO` 自动刷新顶部昵称。

### 2. 个人资料页

- 新增 `src/views/Profile.vue`，沿用白色圆角卡片与 Element Plus 表单风格。
- 展示头像、用户名、等级、注册时间；支持编辑昵称、邮箱、个人简介和性别。昵称必填并去除首尾空格，邮箱允许清空但需校验格式。
- 进入页面通过现有 `getCurrentUser()` 获取最新资料；保存调用 `PUT /api/user/profile`，提供保存、重置、加载及失败重试状态。
- 修改 `src/api/auth.js` 增加 `updateProfile()`；修改 `src/stores/auth.js` 增加仅更新用户资料及 `sg_user` 快照的方法，保存成功后同步顶部用户信息，失败时保留输入。
- 后端复用 `UserController.updateProfile`，补强 `UpdateProfileRequest.java` 与 `UserServiceImpl.java`：昵称/邮箱长度与格式校验、邮箱排他唯一检查、昵称 trim，并确保空邮箱能真正写为 `null`，避免 MyBatis-Plus 忽略空值。

### 3. 我的收藏

- 修改 `src/api/post.js`，增加基于现有 `GET /api/posts` 的 `feed=collected` 封装，继续复用 `toggleCollect()`、`toggleLike()`。
- 修改后端 `PostServiceImpl.getPostList()`：按当前用户查询 `post_collect`，只返回已发布且已收藏的帖子；未登录或无收藏时返回空列表，不能退化为全站帖子；沿用现有分页与 `buildListVO()` 补齐作者、标签、点赞和收藏状态。
- 新增 `src/views/Favorites.vue`，复用 `PostCard.vue` 和 `normalizePost()`，实现首次加载、刷新、加载更多、空状态、失败重试和防重复点击。
- 取消收藏在服务端确认成功后移除卡片；点赞同步更新计数。点击帖子跳转 `/?postId=<id>`，在 `Home.vue` 复用现有 `openDetail()` 和评论弹窗，关闭详情时仅清理 `postId` 查询参数。

### 4. 用户反馈

- 在截图所示用户下拉菜单增加“用户反馈”，点击打开新增 `src/components/FeedbackDialog.vue`。
- 表单包含反馈类型（问题/建议/其他）、反馈内容（必填，最多 1000 字）和可选联系邮箱（默认带出当前用户邮箱）；提交时附带当前页面路径。
- 新增 `src/api/feedback.js`，调用 `POST /api/feedback`。提交期间防重复操作；成功后关闭并重置，失败保留内容。
- 按后端现有分层新增 `FeedbackController`、service、mapper、`Feedback` 实体和创建 DTO。用户 ID 只从 `@AuthenticationPrincipal` 获取，使用 Jakarta Validation 和统一 `Result` 响应；现有认证配置无需放开该接口。
- 新增 `docs/个人中心与反馈增量.sql`，仅包含 `CREATE TABLE IF NOT EXISTS user_feedback` 及必要索引/外键，保存用户、类型、内容、联系方式、页面路径、处理状态和创建时间。仅执行该增量语句，不运行包含 `DROP TABLE` 的旧初始化脚本，也不修改现有用户/收藏表。

## 验证

1. 前端运行 `npm run build`，后端运行 `mvn test`，修复编译问题。
2. 浏览器验证下拉导航、个人资料保存/重置/刷新持久化、顶部昵称同步，以及非法或重复邮箱、清空邮箱等边界。
3. 在首页收藏帖子后进入“我的收藏”，确认列表、详情、点赞、取消收藏、分页、空状态和接口失败状态；换账号确认数据隔离。
4. 在菜单打开反馈弹窗，校验必填和邮箱格式、重复提交、成功重置及失败保留；确认数据库反馈记录的用户 ID、页面路径和内容正确。
